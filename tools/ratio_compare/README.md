# 경쟁률 외부 대조 도구 (2026학년도 기준)

대행사(진학어플라이·유웨이어플라이) **최종 경쟁률 페이지**를 받아 우리 `data.js` 의 `c26` 과
`전형 × 모집단위` 로 대조한다. 2026-09-01 에 135개 대학을 대조해 상명대(천안) 행 밀림 17행,
단국대 3건, 백석대 2건을 찾아냈다.

## 쓰는 법
```bash
# 1) 페이지 수집 — agency_links.json 의 대학별 '26' 링크를 받는다(유웨이는 EUC-KR → iconv 필요)
#    pages/NNN.html 로 저장하고 pages/index.tsv 에 'NNN<TAB>대학명<TAB>kind<TAB>크기<TAB>URL' 을 쓴다.
# 2) 대조
python3 ratio_compare.py
```

## ⚠️ 반드시 알고 쓸 것

**1. 대행사 페이지는 정본이 아니다.** 창신대 공식 발표에
"해당 경쟁률은 인터넷접수(진학어플라이) 및 **대학접수** 건이 포함된 내용입니다" 라고 적혀 있고,
대행사 페이지는 앞의 채널만 담는다. 모집인원은 양쪽 같은데 지원인원만 3,297 vs 1,240 이었다.
**불일치가 곧 우리 오류가 아니다.**

**2. '최종' 문구가 없는 페이지는 마감 전 스냅샷이다.** 135개 중 7교
(경동대·공주교대·국민대·극동대·상지대·선문대·울산대)가 그렇다. 경동대는 페이지 스스로
"경쟁률 현황은 09.12.(금) 16시까지 제공 / 최종은 09.13.(토) 10시 공고" 라고 밝힌다.
절단본과 최종본의 차이는 배율 약 1.09배다(경동대 34건 실측, 최대 1.28).

**3. 링크가 다른 대학을 가리킬 수 있다.** 원본 QR 자료에서 대진대 링크가 대전대 페이지였다.
`ratio_compare.py` 의 `BAD_LINK` 에 넣어 스킵한다. 페이지 `<title>` 을 먼저 확인하라.

**4. 매칭 규칙을 함부로 느슨하게 하지 마라.** 네 번 고쳐 가며 얻은 규칙이다(`ratio_match.py`).
느슨하게 했더니 불일치가 162 → 1,143 으로 폭증했고 전부 오탐이었다. 실제로 겪은 오매칭 —
`경영학과`⊂`관광경영학과`, `국어교육과`⊂`한국어교육과`, `인문대학 자율학부`↔`인문대학`,
`화학과`↔`일본지역문화**학과**`(끝글자 우연), `상경학부(야)`↔`상경학부`,
계명대 `학생부교과(일반전형)`과 `학생부종합(일반전형)`이 한 키로 병합.

**5. 미매칭은 오류가 아니다.** 우리가 페이지보다 잘게 쪼개진 1:N 관계(전자공학부-인공지능 vs
전자공학부)는 자동 매칭이 원리적으로 불가능하다. 미매칭으로 두는 것이 옳다.

## 알려진 파서 결함 (2026-09-01, 미수정)

전수 대조에서 나온 오탐 6건이 **전부 아래 세 가지**에서 나왔다. 고치기 전까지 결과를 사람이 확인해야 한다.

**1. JS 동적 병합 미인식 — 가장 시급 (오탐 3건)**
중부대 페이지는 모집인원 0 인 세부트랙 행을 앞 행 풀에 병합하고
`(그룹 지원합) ÷ (선두 모집)` 으로 경쟁률을 **다시 렌더링**한다(`personnelMerge`/`applicantMerge`/`subNameMerge`).
파서는 정적 HTML 만 읽어 병합 **전** 값을 화면값으로 착각한다.
· 만화애니메이션 — 정적 455/53=8.58, 실제 화면 (455+573)/53=**19.40**
· 산업디자인 — 정적 209/38=5.50, 실제 (209+23)/38=**6.11**
· 경찰경호 — 정적 9/12=0.75, 실제 (9+26+14+1+0+1+0+4)/12=**4.58**
👉 **검출 신호는 '모집인원 0 인 행의 존재' 그 자체다.** 그 표는 병합 시뮬레이션이 필요하다.

**2. rowspan 부모 셀을 학과명으로 오독 (오탐 2건)**
`<td rowspan=6>실용음악학과</td>` 처럼 접힌 상위 셀을 모집단위로 잡고 첫 자식 행 숫자를 붙인다.
· 경기대 실용음악학과 — 보컬(424/5=84.80)에 작곡 행(51/5=10.20)이 붙었다
· 연세대 진리자유학부 — (자연) 행에 (인문) 값 83.58 이 붙었다
👉 rowspan/colspan 구조를 보존해 **상위 셀은 그룹 라벨, 하위 셀을 모집단위**로 분리해야 한다.

**3. 총계·소계 행 흡수 (오탐 1건)**
표 마지막 학과 행 뒤의 총계 행이 그 학과에 딸려 들어갔다
(조선대 태권도 특기자 — 총계 148/64=**2.31** 이 학과 값으로 기록됐다).
👉 '총계/소계/합계' 행 제외 + **우리 값이 표 총계와 소수 둘째 자리까지 같으면 경고**.

## 이번에 유효했던 반증 도구 두 가지 (상설화 권장)
· **소계·총계 역검산** — 섹션의 모집합·지원합이 표 총계와 맞는지. 숨은 병합 행 유무를 가른다.
  건국대·부산대·을지대·인하대·진주교대·조선대 판정의 결정적 근거였다.
· **2026 모집인원 복원** — `enroll(2027) + prev 증감` 으로 2026 모집인원을 만들어 페이지와 대조.
  학과명이 어긋난 경우(경북대 IT 자율학부)에도 행의 정체를 확정해 준다.
