# 경쟁률 외부 대조 도구 (2026학년도 기준)

대행사(진학어플라이·유웨이어플라이) **최종 경쟁률 페이지**를 받아 우리 `data.js` 의 `c26` 과
`전형 × 모집단위` 로 대조한다. 2026-09-01 에 135개 대학을 대조해 상명대(천안) 행 밀림 17행,
단국대 3건, 백석대 2건을 찾아냈다.

## 쓰는 법
```bash
# 1) 페이지 수집 — agency_links.json 의 대학별 '26' 링크를 받는다(유웨이는 EUC-KR → iconv 필요)
#    pages/NNN.html 로 저장하고 pages/index.tsv 에 'NNN<TAB>대학명<TAB>kind<TAB>크기<TAB>URL' 을 쓴다.
# 2) 대조
python3 ratio_compare.py
```

## ⚠️ 반드시 알고 쓸 것

**1. 대행사 페이지는 정본이 아니다.** 창신대 공식 발표에
"해당 경쟁률은 인터넷접수(진학어플라이) 및 **대학접수** 건이 포함된 내용입니다" 라고 적혀 있고,
대행사 페이지는 앞의 채널만 담는다. 모집인원은 양쪽 같은데 지원인원만 3,297 vs 1,240 이었다.
**불일치가 곧 우리 오류가 아니다.**

**2. '최종' 문구가 없는 페이지는 마감 전 스냅샷이다.** 135개 중 7교
(경동대·공주교대·국민대·극동대·상지대·선문대·울산대)가 그렇다. 경동대는 페이지 스스로
"경쟁률 현황은 09.12.(금) 16시까지 제공 / 최종은 09.13.(토) 10시 공고" 라고 밝힌다.
절단본과 최종본의 차이는 배율 약 1.09배다(경동대 34건 실측, 최대 1.28).

**3. 링크가 다른 대학을 가리킬 수 있다.** 원본 QR 자료에서 대진대 링크가 대전대 페이지였다.
`ratio_compare.py` 의 `BAD_LINK` 에 넣어 스킵한다. 페이지 `<title>` 을 먼저 확인하라.

**4. 매칭 규칙을 함부로 느슨하게 하지 마라.** 네 번 고쳐 가며 얻은 규칙이다(`ratio_match.py`).
느슨하게 했더니 불일치가 162 → 1,143 으로 폭증했고 전부 오탐이었다. 실제로 겪은 오매칭 —
`경영학과`⊂`관광경영학과`, `국어교육과`⊂`한국어교육과`, `인문대학 자율학부`↔`인문대학`,
`화학과`↔`일본지역문화**학과**`(끝글자 우연), `상경학부(야)`↔`상경학부`,
계명대 `학생부교과(일반전형)`과 `학생부종합(일반전형)`이 한 키로 병합.

**5. 미매칭은 오류가 아니다.** 우리가 페이지보다 잘게 쪼개진 1:N 관계(전자공학부-인공지능 vs
전자공학부)는 자동 매칭이 원리적으로 불가능하다. 미매칭으로 두는 것이 옳다.
