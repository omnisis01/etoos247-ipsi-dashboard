# 대학어디가 전형결과 수집·대조 (2026학년도 결과)

대교협 대입정보포털(adiga.kr)의 **대학별 전형 평가기준 및 전년도 결과공개**를 받아
`data.js` 의 `g26`(2026 입결 등급)과 대조한다.

## 쓰는 법
```bash
python3 adiga_fetch.py 서울대학교 연세대학교 ...   # 인자 없으면 201개교 전부
python3 adiga_compare.py
```

## 왜 어디가인가
대학이 법령에 따라 제출하는 **공식 등록 자료**이고 표기가 표준화돼 있다. 개별 대학 홈페이지는
형식이 제각각이고 **아예 안 올리는 곳도 있다** — 서울대는 학과별 입결을 공개하지 않는다
(입학자료실에 선발인원·출신지역 집계 보도자료만 있다). 어디가에는 서울대 결과도 있다.

## ⚠️ 반드시 알고 쓸 것

**1. 엔드포인트는 2026-07 이후 개편됐다.** 예전 경로·코드로는 빈 응답이 온다.
```
POST /uct/acd/ade/criteriaAndResultPopupUnvAjax.do   → 대학 201개 코드
POST /uct/acd/ade/criteriaAndResultItemNewAjax.do    → 결과 표
     searchSyr=2027 · unvCd=<7자리> · tsrdCmphSlcnArtclUpCd=<20|30|40> · compUnvCd=<빈 문자열>
```
- `compUnvCd` 를 빠뜨리거나 `null` 로 보내면 `{"error":{"code":"041","message":"잘못된 매개 변수입니다."}}`.
  **빈 문자열이어야 한다.**
- 탭 코드 **10은 공통이라 결과표가 없다**(20=종합·30=교과·40=수능위주). 10으로 받고
  "표가 없다"고 판단하면 안 된다 — 실제로 그렇게 한 번 헛짚었다.
- CSRF 토큰은 필요 없다. 홈으로 세션 쿠키만 한 번 받으면 된다.

**2. 경쟁률을 매칭 검증자로 써라.** 등급이 안 맞을 때 '행을 잘못 짝지었나'와 '값이 다른가'를
가르는 게 전부다. 실측 — 한국외대 3건은 등급이 어긋났는데 **경쟁률도 어긋나** 매칭 오류였고,
같은 대학의 나머지 111행은 70%컷과 정확히 일치했다.

**3. 어디가는 대학에 따라 소수 1자리로 싣는다.** 홍익대 34건이 전부 이것이다(우리 1.83 vs 어디가 1.8).
**우리가 더 정밀하다 — 교정 근거로 쓰지 마라.**

**4. 어디가도 무오류가 아니다.** context-notes (46) 에 강원대 의예과·대전대 중등특수·시립대 경영학부
오류 사례가 있다. |Δ| 가 큰 건은 반드시 개별 확인하고, 기계적으로 덮어쓰지 마라.

**5. 50%컷과 70%컷을 함께 준다** — 이게 이 자료의 가장 큰 가치다. 우리 `stdK26` 라벨이 맞는지
검증할 수 있다. 실측으로 서울시립대 지역균형선발 27행이 라벨은 70%컷인데 값은 50%컷이었다.
